一、服务内容

1. Conflux 是一款个人内容收藏与阅读工具，帮助你将网页、微信、抖音、B 站、小红书、快手、即刻等平台的链接存入同一收藏库，并尽量解析标题、封面、正文等信息，供你个人检索、阅读、标注与整理。
2. 你可通过系统分享、复制链接后打开本应用、粘贴链接、iOS 快捷指令等方式入库。
3. 我们可能持续改进解析能力与功能，但不保证对所有平台、所有链接均能完整解析，也不保证第三方页面长期可访问。

二、账号

1. 本应用采用手机号 + 短信验证码登录；验证通过即完成登录，若该手机号尚无账号将自动注册。
2. 你应保证所提供手机号为你本人合法使用，并对账号下的操作负责。
3. 请妥善保管登录态。如发现账号异常，请及时退出登录并与我们联系。
