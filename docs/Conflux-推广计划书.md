# Conflux · 宣传推广计划书

> 版本：v1.0  
> 日期：2026-08-17  
> 状态：产品功能基本可用，进入「可对外试用 + 冷启动获客」阶段  
> 说明：本文基于当前产品能力（多平台链接解析、系统分享、剪贴板入库、iOS 快捷指令、阅读页等）制定，可随上架进度与数据反馈迭代。

---

## 一、背景与目标

### 1.1 产品一句话

**Conflux**：把抖音 / 微信 / B 站 / 小红书 / 快手 / 36氪等「刷到的好内容」一键存起来，自动抽标题、封面与正文，之后搜得到、读得进。

### 1.2 当前阶段判断

| 维度 | 现状 |
|------|------|
| 核心能力 | 多平台解析、系统分享入库、剪贴板自动保存、iOS 快捷指令、阅读/详情 |
| 分发形态 | 真机 Ad Hoc / 蒲公英等内测为主（正式商店上架仍需补齐图标、隐私政策等） |
| PC / Web | 延后；先吃透手机端「收」的场景 |
| 主要矛盾 | 从「能用」到「有人知道、愿意装、持续用」 |

### 1.3 推广总目标（建议 90 天）

1. **认知**：让目标用户听到一句话就能懂「这是干嘛的」。  
2. **安装**：完成第一批稳定种子用户（建议目标见下文分阶段数字）。  
3. **留存**：验证「存了还会回来看」——否则只是下载器。  
4. **口碑**：沉淀可转发的案例与话术，为商店上架后的放量做准备。

### 1.4 建议量化目标（可按资源砍半/翻倍）

| 周期 | 新增安装 | 周活（WAU） | 核心行为 |
|------|----------|------------|----------|
| 第 1–30 天（冷启动） | 80–200 | 40–100 | 人均收藏 ≥ 3 条 |
| 第 31–60 天（放大） | 累计 400–800 | 150–300 | 次周留存 ≥ 25% |
| 第 61–90 天（验证） | 累计 1000+ | 350–600 | 次周留存 ≥ 30%，NPS 收集 ≥ 50 份 |

> 内测阶段以「高质量种子」优先，不强求虚高下载量。

## 二、定位与差异化

### 2.1 用户真正在痛什么

- 抖音 / 小红书 / B 站里看到有用内容，**收藏夹乱、难找回、难跨平台统一**。  
- 微信文章、公众号，**收藏后像沉海**。  
- 复制链接到备忘录 / 浏览器书签，**没有标题封面，不可读**。  
- 现有「稍后读」工具对国内短视频 / 图文平台支持弱或体验差。

### 2.2 我们的卖点（对外只讲 3 条）

1. **一键收**：系统分享 / 复制即存 / iOS 快捷指令，尽量少打断刷内容。  
2. **自动懂**：解析标题、封面、图集/视频/正文，不是裸链。  
3. **以后找得到**：集中在一个 App 里搜、读（后续可讲合集/标注，视功能成熟度）。

### 2.3 不建议主打的话

- 「第二大脑 / AI 知识库」（期望过高，当前交付对不上）。  
- 「完全后台不打开 App 也能解析所有平台」（抖音仍需 App 内 WebView，易打脸）。  
- 「替代微信/抖音收藏」（用户不会为替代而来，只会为「更好找回」而来）。

### 2.4 一句话 Slogan 备选

- 「刷到好内容，一键收进 Conflux」  
- 「链接会过期，收藏要可读」  
- 「跨 App 收藏，一个地方找回来」

## 三、目标用户与场景

### 3.1 一级用户画像（优先）

| 画像 | 特征 | 典型场景 | 获客入口 |
|------|------|----------|----------|
| A. 知识/职场收集者 | 常存微信文章、36氪、B 站教程 | 通勤刷到 → 分享入库 → 周末读 | 小红书/即刻/即刻类职场群 |
| B. 短视频素材党 | 抖音/快手/小红书存灵感、案例 | 刷到 → 分享「Conflux」 | 抖音评论区/创作者社群 |
| C. 重度稍后读用户 | 已用过 Cubox、Raindrop、备忘录堆链接 | 对比「国内平台解析」 | 少数派、V2EX、即刻 |

### 3.2 关键时刻（Must-win Moments）

1. **第一次成功存进一条抖音/微信**，并在 App 里看到正确封面标题。  
2. **第二次从分享面板一眼找到「Conflux」**（引导用户「编辑」置顶）。  
3. **三天后还能搜到并点开阅读**。

任一环节失败，推广预算基本浪费。

## 四、上架与分发准备（推广前置）

在大规模投放前，建议先完成：

| 事项 | 原因 | 优先级 |
|------|------|--------|
| App Store / 国内商店正式包 | 降低安装摩擦，利于自然传播 | P0 |
| 正式图标 + 启动图 | 分享面板与桌面认知 | P0 |
| 隐私政策 / 用户协议 | 审核与信任 | P0 |
| 稳定测试群 + 崩溃监控 | 避免「种草后差评」 | P0 |
| 落地页（1 页即可） | 统一话术、安装入口、教程 | P0 |
| TestFlight / 应用宝等双通道 | iOS + Android 都覆盖 | P1 |
| 客服入口（微信企微/邮箱） | 内测期问题收敛 | P1 |

**落地页建议模块**：一句话价值 → 三步怎么用（分享/复制/快捷指令）→ 支持平台 → 安装按钮 → 常见问题（微信分享、抖音首次解析、如何置顶分享图标）。

## 五、分阶段推广策略

### 阶段 0：内部打磨（1–2 周，可与推广并行）

- 固定 10–20 名真实用户每周反馈。  
- 必测：抖音视频/图文、微信文章、B 站、系统分享置顶引导。  
- 产出：FAQ、30 秒演示视频、3 条种草文案模板。

### 阶段 1：种子冷启动（第 1–30 天）

**原则**：人肉、精准、高反馈，不烧钱。

1. **个人/团队人脉**  
   - 朋友圈 + 微信群：发「我自己在用」的真实收藏截图，附安装与三步教程。  
   - 目标：每人带来 5–10 个愿装愿用的人。

2. **内容社区种草（免费为主）**  
   - 小红书：教程向（「怎么把抖音收藏整理到一个 App」）。  
   - 即刻：产品/效率圈短评。  
   - 少数派 / V2EX：偏硬核「国内平台解析」角度（注意社区发帖规范）。  
   - B 站：60–90 秒录屏演示「分享 → 入库 → 阅读」。

3. **垂直社群**  
   - 读书会、运营学习群、创作者互助群：提供「内测码换反馈」。

4. **激励**  
   - 内测用户：优先体验 + 正式版纪念（或后续会员试用），换取问卷与好评素材。

### 阶段 2：内容放大（第 31–60 天）

**原则**：可复制内容 × 轻投放。

1. **内容矩阵**  
   - 每周 3–5 条短内容：对比「备忘录堆链接 vs Conflux」、平台清单、快捷指令教程。  
   - 统一标签/话题：如 `#Conflux` `#稍后读` `#抖音收藏整理`。

2. **达人/博主**  
   - 找 5–15 个中小效率/职场/读书博主（粉丝 1万–20万）送内测。  
   - 合作形式：体验笔记 / 录屏，不硬广；按效果续约。

3. **轻量付费**  
   - 小红书/抖音信息流小预算测试（日预算可控），只投「安装 + 首次收藏」转化，不投虚曝光。  
   - 先验证 1–2 条素材，再放量。

### 阶段 3：渠道与口碑（第 61–90 天）

1. **应用商店 ASO**  
   - 关键词：收藏、稍后读、抖音收藏、微信收藏整理、链接保存等。  
   - 截图讲清「三步入库 + 支持平台」。

2. **邀请机制（可选）**  
   - 邀请好友双方各得「解析加速/容量」等（需产品配套；没有就先不做）。

3. **媒体/榜单**  
   - 新品榜、效率工具合集投稿；中文独立开发/产品Hunt 类社区。

## 六、内容与话术体系

### 6.1 核心演示脚本（30 秒）

1. 打开抖音/微信，点分享 →「Conflux」。  
2. 切回 App，看到进度与条目封面标题。  
3. 点进阅读页，强调「不是一条蓝链」。

### 6.2 种草文结构（小红书/朋友圈通用）

1. 痛点开头（收藏找不到）。  
2. 我怎么用（分享 / 复制）。  
3. 结果截图（列表 + 详情）。  
4. 注意点（分享面板「编辑」置顶；抖音首次可能稍慢）。  
5. 安装方式。

### 6.3 必备 FAQ（客服与评论区）

| 问题 | 回答要点 |
|------|----------|
| 微信里找不到？ | 用系统分享入口；或复制链接后打开 App；分享面板可「编辑」打开并置顶。 |
| B 站有时没有？ | 分享常带封面图；已支持附带图片时显示；左右滑找图标。 |
| 抖音快捷指令？ | 会先入库，打开 App 后自动用本机解析（更稳）。 |
| 和 Cubox 比？ | 更针对国内短视频/公众号一键收与可读化（按真实能力表述）。 |
| 是否收费？ | 按你们定价策略写清：内测免费 / 正式版基础免费等。 |

### 6.4 素材清单

- [ ] App 图标（多尺寸）  
- [ ] 5 张商店截图（入库三路径、列表、阅读、多平台）  
- [ ] 30 秒 / 60 秒演示视频  
- [ ] 静图对比（备忘录 vs 本 App）  
- [ ] 落地页首屏 KV

## 七、增长飞轮（产品侧配合）

推广不是纯广告，建议产品上预留「可传播点」：

1. **首次成功引导**：第一次入库成功后，提示「去分享面板编辑，把 Conflux 拖到前面」。  
2. **空状态文案**：直接教三步，而不是空白。  
3. **可分享成就（弱）**：如「本周收藏了 12 条」生成卡片（可选，勿过度）。  
4. **反馈入口**：设置里一键反馈 + 日志开关（便于修解析问题）。  
5. **平台覆盖清单页**：用户爱转发「支持哪些 App」。

## 八、数据指标与复盘

### 8.1 北极星指标

**「每人每周成功解析入库条数」**（比纯 DAU 更能反映价值）。

### 8.2 漏斗

`曝光/访问落地页 → 安装 → 登录 → 首次入库成功 → 次日回访 → 第 7 日仍有阅读/搜索`

每一环标注失败原因（解析失败、找不到分享入口、不会用等）。

### 8.3 周复盘模板

1. 本周新增 / 留存 / 人均收藏。  
2. Top 解析失败平台与原因。  
3. 哪条内容/渠道带来最多「首次入库成功」。  
4. 下周只押注 1–2 个渠道加深，避免撒胡椒面。

## 九、预算建议（弹性）

| 项目 | 低配（自力） | 中配 | 说明 |
|------|--------------|------|------|
| 落地页 / 域名 | 0–500 | 500–2000 | 可用现成建站 |
| 设计（图标截图视频） | 0–自做 | 2000–8000 | 强烈建议至少图标专业 |
| 达人样品/小额合作 | 0–1000 | 3000–15000 | 按篇或按效果 |
| 信息流测试 | 0 | 2000–10000 | 验证素材用 |
| 合计（90 天） | ≈0–3k | ≈1–3 万 | 内测期够用 |

## 十、风险与合规

1. **版权与解析展示**：宣传强调「个人收藏与阅读」，避免「下载盗版/搬运」话术。  
2. **平台政策**：勿教用户破解、勿承诺永久视频直链。  
3. **隐私**：剪贴板、分享内容仅用于用户主动收藏；隐私政策写清楚。  
4. **预期管理**：个别 App 无系统分享、抖音首次解析偏慢等，公开说明比隐瞒好。  
5. **差评风险**：上架前把崩溃与主流平台成功率做到可接受阈值。

## 十二、90 天行动日历（摘要）

### 第 1–2 周

- 定 Slogan、落地页上线、FAQ、演示视频。  
- 拉满种子群；修 Top 反馈。  
- 商店材料启动（图标/隐私政策）。

### 第 3–4 周

- 小红书/即刻/B 站持续种草。  
- 收集 20 份用户访谈（为何装、卡在哪）。  
- 优化首次成功引导（分享置顶提示）。

### 第 5–8 周

- 达人合作 5+；小预算投放测素材。  
- 正式上架（若材料就绪）。  
- ASO 与商店页迭代。

### 第 9–12 周

- 看留存决定：加邀请、加合集能力，或继续打磨解析。  
- 输出一版「公开复盘」建立信任。

## 十三、成功标准（阶段门）

满足以下多数项，再考虑明显加预算：

- [ ] 首次入库成功率（主流平台合计）达到可对外承诺水平  
- [ ] 次周留存 ≥ 25%  
- [ ] 至少 3 条可复用的爆款/长尾内容素材  
- [ ] 客服问题可被 FAQ 覆盖 70% 以上  
- [ ] 商店页或落地页转化率可测、可优化

## 十四、附录：对外一页纸话术

**Conflux** 帮你把抖音、微信、B 站、小红书等内容，用「系统分享 / 复制链接 / 快捷指令」一键收进同一个 App，自动整理标题和封面，之后随时搜、随时读。  

适合：总收藏找不到的人、想把碎片信息收成可读库的人。  

现在：安装 → 登录 → 去任意内容 App 点分享选「Conflux」（建议在分享面板「编辑」里置顶）→ 回 App 查看。
