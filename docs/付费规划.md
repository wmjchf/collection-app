# 付费规划（奏折）

> 状态：三档 **普通 / 太子 / 帝王** 已实现（功能门控 + 月额度）；iOS IAP 四商品（太子月年 + 帝王月年）  
> 更新日期：2026-09-04

## 1. 档位

| 能力 | 普通 | 太子 | 帝王 |
| --- | --- | --- | --- |
| 在库收藏条数 | 固定上限（默认 300，不含已删除） | 不限 | 不限 |
| AI 标签 | ❌ | ✅（月 token 池） | ✅ |
| AI 解读（总结） | ❌ | ✅（共用 token 池） | ✅ |
| AI 思维导图 | ❌ | ❌ | ✅（共用 token 池） |
| 视频/音频转写 | ❌ | ❌ | ✅（月分钟池） |
| 阅读 / 搜索 / 手动标签 | ✅ | ✅ | ✅ |

**帝王包含太子全部能力。** 已生成内容始终可查看；限制的是新的消耗型调用。

## 2. 计量

- **条数**：仅统计 `deleted_at IS NULL`；入库前触顶 402
- **AI**：按 DashScope 返回 `total_tokens` 入账（标签 / 总结 / 脑图共用一池，按档位给月上限）
- **转写**：按成功转写的媒体秒数折算分钟；仅帝王可用

## 3. iOS 订阅

同一订阅群组内四件商品：

| 档位 | Product ID（默认） |
| --- | --- |
| 太子月付 | `com.bufang.supercollection.monthly` |
| 太子年付 | `com.bufang.supercollection.yearly` |
| 帝王月付 | `com.bufang.supercollection.emperor.monthly` |
| 帝王年付 | `com.bufang.supercollection.emperor.yearly` |

校验：`POST /api/billing/apple/verify` → `subscriptions.plan` = `prince` | `emperor`（legacy `pro` 等同太子）。

## 4. 环境变量（默认）

| 变量 | 默认 |
| --- | --- |
| `FREE_ITEM_LIMIT` | 300 |
| `FREE_AI_TOKENS_PER_MONTH` | 0 |
| `FREE_TRANSCRIPT_MINUTES_PER_MONTH` | 0 |
| `PRINCE_AI_TOKENS_PER_MONTH` | 500000 |
| `EMPEROR_AI_TOKENS_PER_MONTH` | 1000000 |
| `EMPEROR_TRANSCRIPT_MINUTES_PER_MONTH` | 200 |
| `USAGE_ENFORCING` | true |

开发：`POST /api/billing/dev/grant-pro`（太子）、`…/grant-emperor`（帝王）、`…/revoke-pro`（取消全部）。

## 5. API

- `GET /api/usage`：`plan`、`planLabel`、`features`、`storage`、`transcript`、`ai`
- 触顶：`402` + `QUOTA_EXCEEDED`（额度）或 `PLAN_REQUIRED`（档位不足，`requiredPlan` 字段）
