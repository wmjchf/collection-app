# 付费规划（奏折）

> 状态：三档 **普通 / 太子 / 帝王** 已实现（功能门控 + 月额度）；iOS IAP 四商品（太子月年 + 帝王月年）；**月付可配 7 天免费试用**  
> 更新日期：2026-09-13

## 1. 档位

| 能力 | 普通 | 太子 | 帝王 |
| --- | --- | --- | --- |
| 在库收藏条数 | 固定上限（默认 300，不含已删除） | 不限 | 不限 |
| AI 标签 | ❌ | ✅（月 token 池） | ✅ |
| AI 解读（总结） | ❌ | ✅（共用 token 池） | ✅ |
| AI 思维导图 | ❌ | ❌ | ✅（共用 token 池） |
| 视频/音频转写 | ❌ | ❌ | ✅（月分钟池） |
| 阅读 / 搜索 / 手动标签 | ✅ | ✅ | ✅ |

**帝王包含太子全部能力。** 已生成内容始终可查看；限制的是新的消耗型调用。

## 2. 计量

- **条数**：仅统计 `deleted_at IS NULL`；入库前触顶 402
- **AI**：按 `(prompt_tokens - cached_tokens) + completion_tokens` 入账（缓存部分不计入用户额度；标签 / 总结 / 脑图共用一池）
- **转写**：按成功转写的媒体秒数折算分钟；仅帝王可用

### 3.1 月付免费试用（Introductory Offer）

**仅两个月付 SKU** 配置 7 天免费试用；年付不加试用。

App Store Connect 步骤（每个月付商品各做一次）：

1. 打开订阅 → 对应月付商品 → **订阅价格** / Introductory Offers
2. 新建 Introductory Offer：类型选 **Free**，时长 **7 days**
3. 适用国家/地区按上架范围勾选；新用户（该订阅群组内未用过 intro）可领

App 行为：

- StoreKit 读到 `introductoryPrice` / SK2 introductory + 用户仍有资格时，升级页月付展示「免费试用 N 天，之后 ¥x/月」，CTA「免费试用 N 天」
- 年付文案不变
- 试用期内验单仍按 `expiresDate` 开通档位；到期由 Apple 自动续费扣第一期月费（无需改后端验单）
- **站内到期提醒**：试用结束前 48 小时内，`GET /api/usage` 返回 `trialReminder`；首页与账户页展示可关闭横条（「管理订阅」链到 App Store）

> ASC 未配 offer 时，App 不会显示试用文案（StoreKit 无 intro 字段）。

## 4. 环境变量（默认）

| 变量 | 默认 |
| --- | --- |
| `FREE_ITEM_LIMIT` | 300 |
| `FREE_AI_TOKENS_PER_MONTH` | 0 |
| `FREE_TRANSCRIPT_MINUTES_PER_MONTH` | 0 |
| `PRINCE_AI_TOKENS_PER_MONTH` | 500000 |
| `EMPEROR_AI_TOKENS_PER_MONTH` | 1000000 |
| `EMPEROR_TRANSCRIPT_MINUTES_PER_MONTH` | 200 |
| `USAGE_ENFORCING` | true（设 `false` 时本地跳过额度与档位拦截） |

开发：`POST /api/billing/dev/grant-pro`（太子）、`…/grant-emperor`（帝王）、`…/revoke-pro`（取消全部）。`USAGE_ENFORCING=false` 时可不授权直接测 AI。

## 5. API

- `GET /api/usage`：`plan`、`planLabel`、`features`、`storage`、`transcript`、`ai`
- `GET /api/usage/events?kind=ai|transcript`：本月用量明细（关联收藏标题；已删条目读 `meta.itemTitle` 快照）
- 触顶：`402` + `QUOTA_EXCEEDED`（额度）或 `PLAN_REQUIRED`（档位不足，`requiredPlan` 字段）
