# 付费规划（收藏家 / Conflux）

> 状态：产品约定（未实现计费代码）  
> 更新日期：2026-08-28

## 1. 原则

| 能力 | 策略 |
| --- | --- |
| 收藏、**解析**、阅读、搜索、手动标签、系统分类 | **永久免费**，解析不设墙、不限次 |
| 转写（ASR） | 每月免费**分钟**额度；超额需订阅 |
| AI 标签建议 | 按「成功生成次数」计月额度；超额需订阅 |
| AI 思维导图 | 同上（与标签**分列额度**） |

已生成内容（文稿、脑图、已采纳标签）**始终可查看**；额度只限制**新的消耗型调用**。

## 2. 订阅形态

- 初期只做一档：**Pro**（月付 + 年付折扣）
- 免费用户与 Pro 用户：**解析与基础能力完全一致**
- Pro：转写（分钟）/ AI 标签 / AI 脑图的**月额度更高**

额度数字待有真实用量后再定；实现前先做用量埋点（见 §6）。

## 3. 计量维度

### 3.1 转写（按分钟）

- **计量单位：音频/视频时长（分钟）**，与阿里云 ASR 成本对齐
- 以**转写成功**后确认的媒体时长入账（优先用 ASR/探测得到的 `durationSec`）
- **按实际时长计**：不足 1 分钟也按真实秒数折算分钟（例如 30 秒 = 0.5 分钟），**不设「最低扣 1 分钟」**
- 实现上可用「秒」累加，对用户展示为分钟（可一位小数）
- AI 标签 / 脑图触发的**自动先转写**同样按实际时长扣除
- **失败不扣**；同一段「已有成功文稿拒绝重复转写」不扣
- 额度展示示例：「本月转写还剩 42.5 分钟」

### 3.2 AI 标签 / 思维导图

- 按**成功完成一轮模型生成**计 **1 次**（含重新生成）
- **不计**：采纳 / 忽略、查看结果、状态轮询、生成失败
- 标签与脑图**分开额度**，文案更清晰
- 若生成前自动转写：转写扣转写额度，生成成功再扣对应 AI 额度

### 3.3 重新生成与用户方向（产品）

- **首次生成**：一键即可，不强制填写方向
- **重新生成**：弹层提供可选输入框，用户可写期望方向（可空）；有内容则写入模型 prompt
- 目的：重生成是「按意图再跑一版」，而非盲抽；减轻「AI 质量靠用户多付费」的不公平感
- 额度策略（待计费落地时再启用）：正常按次；可选「同条目 24h 内第 2 次重生成不扣」作为缓冲

## 4. 触顶体验

- 入口保持可见
- 触发时提示：转写示例「本月转写分钟已用完，订阅后可继续」；AI 示例「本月 AI 额度已用完，订阅后可继续」
- 引导订阅页；取消则不发起请求

## 5. 支付与合规（后续）

- Android：可微信 / 支付宝（及必要时 IAP）

## 8. 偏好学习（用更少次数贴近用户）

目标：把用户填写的「期望方向」沉淀为偏好，使**首次生成更准、重生成更少**。不做模型微调，用「记忆 + 注入 prompt」。

### 8.1 记什么

| 事件 | 说明 |
| --- | --- |
| 显式方向 | 用户在重新生成（或将来首次可选）时填写的 `direction` |
| 采纳信号（标签） | 用户采纳建议标签 → 强化该次方向（若有） |

表：`ai_preference_events`（用户、条目、`kind`=tags|mindmap、方向原文、可选 outcome）。

### 8.2 怎么用

- **有本次方向**：优先遵循本次；历史偏好仅作弱参考  
- **无本次方向**（含首次生成）：注入该用户该类型**近期去重后的偏好**（默认最多 5 条）  
- 标签 / 脑图偏好**分开**记忆

### 8.3 边界

- 仅存用户主动填写的方向，不存全文内容到偏好表  
- 后续可提供「清除 AI 偏好」；单次方向始终覆盖历史  
- 与额度正交：学习减少必要调用次数，计费仍按成功生成次数

- ✅ 存显式方向 + 首次/无方向时注入近期偏好（迁移 `012`）
