# 付费规划（奏折）

> 状态：四档 **免费 / 普通会员 / 太子 / 帝王** 已实现（功能门控 + 月额度）；三档付费均为月/年订阅；**太子/帝王国付可配 7 天免费试用**  
> 更新日期：2026-10-14

## 1. 档位

| 能力 | 免费 | 普通会员 | 太子 | 帝王 |
| --- | --- | --- | --- | --- |
| 在库收藏条数 | 固定上限（默认 100，不含已删除） | 订阅期内不限 | 不限 | 不限 |
| 自动打标 / 归类 | ✅（解析后；不计额度） | ✅ | ✅ | ✅ |
| AI 解读（总结） | ❌ | ❌ | ✅（共用 token 池，默认 flash） | ✅ |
| AI 思维导图 | ❌ | ❌ | ✅（月 token 池，默认 50 万≈5000 积分） | ✅（默认 80 万≈8000 积分，共用池） |
| 视频/音频转写 | ❌ | ❌ | ✅（默认 200 分钟/月） | ✅（默认 400 分钟/月） |
| 阅读 / 搜索 / 手动标签 | ✅ | ✅ | ✅ | ✅ |

**plan 值**：`free` / `basic` / `prince` / `emperor`（legacy `pro` 等同太子）。  
**普通会员只放开收藏条数**；自动打标/归类全员可用。**AI 解读属太子+**（用户主动触发，不计解析后自动）。**太子含普通会员；帝王含太子全部能力，差异主要是更高月额度（AI token / 转写分钟）。** 已生成内容始终可查看；限制的是新的消耗型调用。

## 2. 计量

- **条数**：仅统计 `deleted_at IS NULL`；入库前触顶 402，`requiredPlan: basic`
- **AI**：按 `(prompt_tokens - cached_tokens) + completion_tokens` 入账（缓存部分不计入用户额度；解读 / 脑图 / 手动归类共用一池）；至少太子。**解析后自动打标、自动归类不计用户额度**（仍消耗我方模型费）
- **转写**：按成功转写的媒体秒数折算分钟；太子+ 可用（太子默认 200 分/月，帝王默认 400 分/月）

### 3.1 月付免费试用（Introductory Offer）

**仅太子/帝王国付 SKU** 配置 7 天免费试用；普通会员月付/年付与各档年付不加试用。

App Store Connect 步骤（每个月付商品各做一次）：

1. 打开订阅 → 对应月付商品 → **订阅价格** / Introductory Offers
2. 新建 Introductory Offer：类型选 **Free**，时长 **7 days**
3. 适用国家/地区按上架范围勾选；新用户（该订阅群组内未用过 intro）可领

App 行为：

- StoreKit 读到 `introductoryPrice` / SK2 introductory + 用户仍有资格时，升级页月付展示「免费试用 N 天，之后 ¥x/月」，CTA「免费试用 N 天」
- 年付文案不变
- 试用期内验单仍按 `expiresDate` 开通档位；到期由 Apple 自动续费扣第一期月费（无需改后端验单）
- **试用额度**：约为对应档位正式月额度的 **1/4**（`TRIAL_QUOTA_FRACTION`，可用 `TRIAL_*` 绝对值覆盖）；能力仍按档位全开，仅限制消耗量。计量仍按自然月累计，转正后升为完整月额度
- **站内试用提醒**：免费试用全程（开始到结束），`GET /api/usage` 返回 `trialReminder`；首页与账户页展示横条，仅用户点 × 关闭（点「管理订阅」不隐藏）

> ASC 未配 offer 时，App 不会显示试用文案（StoreKit 无 intro 字段）。

### 3.2 ASC 新建普通会员月付 / 年付

1. App Store Connect → 订阅 → 现有订阅群组 → 新建两个 **自动续期订阅**
2. Product ID：`com.bufang.supercollection.basic.monthly`、`com.bufang.supercollection.basic.yearly`
3. 显示名称 / 描述注明「订阅期内无限收藏，自动续期」
4. 后端 `APPLE_IAP_PRODUCT_BASIC_MONTHLY` / `_YEARLY` 与 App `IapProductIds.basicMonthly` / `basicYearly` 保持一致
5. 旧非消耗型 `com.bufang.supercollection.basic` 停售、保留可恢复；不要改成订阅，也不要删掉

## 5. API

- `GET /api/usage`：`plan`、`planLabel`、`isTrial`、`features`、`storage`、`transcript`、`ai`；试用中 `planLabel` 带「（试用）」，额度按试用池返回；`features.unlimitedItems` 在 basic+ 为 true
- `GET /api/billing/products`：`products.basic|prince|emperor.monthly|yearly`
- `GET /api/usage/events?kind=ai|transcript`：本月用量明细（关联收藏标题；已删条目读 `meta.itemTitle` 快照）
- 触顶：`402` + `QUOTA_EXCEEDED`（额度）或 `PLAN_REQUIRED`（档位不足，`requiredPlan` 字段）；收藏条数触顶 `requiredPlan: basic`
