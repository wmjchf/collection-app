下载安装包（zip）

下载 Chrome 插件

目前需用开发者模式手动安装（Chrome 网上应用店上架后将提供一键安装）。

  1. 下载上方 zip，解压后得到 extension 文件夹（保持文件夹完整，不要只挑里面的单个文件）。
  2. Chrome 地址栏打开 chrome://extensions。
  3. 右上角打开「开发者模式」。
  4. 点击「加载已解压的扩展程序」，选中刚才解压出的 extension 文件夹。
  5. 点工具栏奏折图标（或固定到工具栏），用与 App 相同的手机号登录。

更新：重新下载 zip 并解压覆盖原文件夹后，在扩展页对该插件点「重新加载」。也可先移除再按上面步骤重装。

更多问题见用户支持

奏折可以收藏什么？

公开链接为主：微信、抖音、小红书、B 站、网页文章等。尽量自动解析标题、封面与正文；部分平台可能受登录或反爬限制。

如何把内容收藏进来？

系统分享选「奏折」、复制链接后打开 App，或安装 iOS 快捷指令后台保存。桌面可用 Chrome 插件。详见使用指引。

标签是自动打的吗？

是。文章解析成功后自动打标签并尽量归类；视频在转写成功后同样处理（图集除外）。也可在阅读页手动增删标签。

需要付费吗？

基础收藏与解析免费（条数有上限）。无限收藏可订阅普通会员；AI 解读、思维导图与转写需太子Pro 或帝王Pro。价格以 App Store 为准。

在哪里下载？

iPhone 请在 App Store 搜索「奏折」。桌面请到官网 Chrome 插件 下载 zip，按页面步骤用开发者模式安装。
