# 奏折 Chrome 扩展（桌面整理端）

浏览器里负责：**存、找、整理**。深读、标注、视频仍以手机 App 为主。

## 安装（开发者模式）

官网下载（推荐给用户）：[conflux.wobufang.com/#chrome](https://conflux.wobufang.com/#chrome) → 下载 zip → 解压得到 `extension` 文件夹。

本地 / 开发：

1. 打开 Chrome → `chrome://extensions`
2. 打开右上角「开发者模式」
3. 「加载已解压的扩展程序」，选本目录 `extension/`（或解压 zip 后的同名文件夹）
4. 点工具栏图标，用和 App 相同的手机号登录
5. 改完代码后，在扩展页点「重新加载」；发新版时更新 `backend/public/downloads/conflux-extension.zip`

## 用法

- **工具栏图标**：从浏览器右侧打开面板（类似 MetaMask）
- **阅读（底栏）**：与 App 一致 — 未读 / 漫游；顶栏蓝加号添加链接
- **漫游**：点叠卡进播放器（上滑、滚轮或点卡看下一则；不再回顾 / 打开原文）；「全部 ›」进列表
- **底栏**：阅读 | 蓝色搜索圆钮 | 收藏（与 App 同构）
- **搜索**：圆角搜索框 + 取消；标签 chip 筛选 + 内容列表（标签/正文双接口）
- **收藏**：系统分类瓷砖（所有/今天/无标签/批注等）+ 归类标签（未归类与模块）；点归类看组内条目；右键删除自建标签
- **详情**：标题、解析状态、封面/正文预览；⋯ 复制链接 / 删除。点链接打开原文。阅读、标注仍在手机 App
- **右键页面 / 链接**：「收藏到 奏折」
- **快捷键**：`Alt + S`（可在 `chrome://extensions/shortcuts` 改）

登录态存在本机 Chrome，与手机 App 是同一套账号，不是同一台设备的会话。

## 说明

请求发往 `https://conflux.wobufang.com`（与 App 相同）。改地址编辑 `config.js` 后重新加载扩展；本地调试可改为 `http://127.0.0.1:3001`。
